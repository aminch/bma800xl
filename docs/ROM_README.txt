Optional Atari ROM images
=========================

BMA800XL works without any ROM files: atari800 includes Altirra OS and
Altirra BASIC, free replacements for the Atari's ROMs.

For the best compatibility, copy real Atari ROM images here (for example
the 800XL OS, Atari BASIC revision C and the 5200 BIOS). Their names don't
matter; atari800 recognises them by their contents.

They are picked up when BMA800XL starts without an atari800.cfg in the root
of the card. If you already have one, delete it, or choose the ROMs in the
menu (F1, System Settings) and use Save Configuration.
